Live AI Object Detection with ESP32-CAM and Python

This guide details how to build a system where an ESP32-CAM acts as a live video camera, streaming its feed over Wi-Fi to a computer. A Python script on the computer then grabs the video, runs a powerful YOLOv8 object detection model on it in real-time, and displays the result in a fullscreen window.

## Part 1: What You'll Need

Hardware ⚙️

    ESP32-CAM Board: The main camera and microcontroller board. The common AI-Thinker model is used here.

    USB-to-Serial Programmer: An FTDI programmer or an ESP32-CAM-MB adapter to upload code from your computer.

    Stable Power Supply: A 5V power adapter that can supply at least 1A (2A is better). Do not rely on your computer's USB port for power as it can cause reboots.

    Jumper Wires: To connect the power supply.

Software & Libraries 💻

    Arduino IDE: With the ESP32 board manager installed.

    Python: Version 3.8 or newer.

    Python Libraries: We'll install these into a virtual environment.

        ultralytics: For the YOLOv8 model.

        opencv-python: For grabbing and displaying the video stream.

        tkinter: Used to get screen size (usually comes standard with Python).

## Part 2: The Camera (ESP32-CAM Setup) 📸

The ESP32's only job is to run a web server that streams video from its camera.

Step 1: The Arduino Code

This is the standard CameraWebServer example.

    Open the Arduino IDE.

    Go to File > Examples > ESP32 > Camera > CameraWebServer.

    In the sketch, make two changes:

        Set your Wi-Fi credentials.

        Ensure the CAMERA_MODEL_AI_THINKER is the only model defined.

C++

// --- CameraWebServer Sketch ---

// Replace with your network credentials
const char* ssid = "YOUR_WIFI_SSID";
const char* password = "YOUR_WIFI_PASSWORD";

// Make sure this is the only camera model uncommented
#define CAMERA_MODEL_AI_THINKER

// --- The rest of the sketch can remain as is ---
// (No need to copy the full sketch here, just modify the example)

Step 2: Upload and Run

    Connect your ESP32-CAM to your computer via the programmer.

    Upload the sketch using the Arduino IDE.

    Disconnect the programmer.

    Power the ESP32-CAM using your 5V external power supply.

    Open the Arduino IDE's Serial Monitor (at 115200 baud). When it connects, it will print its IP address. Note this down (e.g., http://192.168.1.101).

## Part 3: The Brain (Computer Setup) 🤖

The computer will run a Python script to connect to the camera, run the AI, and display the results.

Step 1: Setup Python Environment

It's best practice to create a virtual environment for the project.

    Open your terminal or Command Prompt.

    Navigate to your project folder (e.g., cd C:\Users\vinod\Downloads\practice).

    Create the environment: python -m venv yolovenv

    Activate it: yolovenv\Scripts\activate

Step 2: Install Libraries

With your environment active, run this single command to install everything you need:
Bash

pip install ultralytics opencv-python

Step 3: The Python Code

Create a file named live_detector.py and paste the following complete code into it.
Python

import cv2
from ultralytics import YOLO
import tkinter as tk # Library to get screen size

# --- Automatically get screen resolution ---
# This helps make the window a perfect fit
root = tk.Tk()
screen_width = root.winfo_screenwidth()
screen_height = root.winfo_screenheight()
root.destroy()
# --- --- --- --- --- --- --- --- --- --- ---

# Load the YOLOv8 model. 'yolov8n.pt' is the smallest and fastest.
model = YOLO('yolov8n.pt')

# --- IMPORTANT: UPDATE THIS URL ---
# Use the IP address from your ESP32's Serial Monitor.
# The ":81/stream" part is crucial.
url = 'http://192.168.1.101:81/stream'
# --- --- --- --- --- --- --- --- --- --- ---

# Create a VideoCapture object to connect to the stream
cap = cv2.VideoCapture(url)

# Check if the connection was successful
if not cap.isOpened():
    print("Error: Could not open video stream. Check the URL and network.")
    exit()

# --- Create a named window and set it to fullscreen ---
window_name = "YOLOv8 Live Detection"
cv2.namedWindow(window_name, cv2.WINDOW_NORMAL)
cv2.setWindowProperty(window_name, cv2.WND_PROP_FULLSCREEN, cv2.WINDOW_FULLSCREEN)
# --- --- --- --- --- --- --- --- --- --- --- --- --- ---

print("Connecting to video stream... Press 'q' to quit fullscreen.")

# Main loop to process video frames
while True:
    # Read a single frame from the video stream
    ret, frame = cap.read()

    # 'ret' is a boolean that is True if a frame was read successfully
    if ret:
        # Run the YOLOv8 model on the frame
        results = model(frame)

        # The .plot() method draws the detection boxes and labels on the frame
        annotated_frame = results[0].plot()

        # Resize the frame to fit your laptop's screen perfectly
        resized_frame = cv2.resize(annotated_frame, (screen_width, screen_height))

        # Display the final, resized frame in the fullscreen window
        cv2.imshow(window_name, resized_frame)

        # Wait for 1 millisecond. If the 'q' key is pressed, break the loop.
        # This cv2.waitKey() call is essential for the window to display.
        if cv2.waitKey(1) & 0xFF == ord('q'):
            break

    else:
        # If 'ret' is False, the stream has been disconnected
        print("Stream disconnected.")
        break

# --- Cleanup ---
# Release the video capture object
cap.release()
# Destroy all OpenCV windows
cv2.destroyAllWindows()
print("Stream closed and resources released.")

## Part 4: Troubleshooting & Key Reminders 💡

If you run into issues later, remember the key problems we solved:

    "Detected camera not supported" Error: The wrong camera model was selected in the Arduino code. Always use #define CAMERA_MODEL_AI_THINKER.

    Constant Reboots: This is a power issue. You must use a strong, external 5V power supply.

    "Could not open video stream" Error: This has several causes:

        The URL is wrong: Use the browser's "Inspect" tool to find the exact stream URL, including the port (like :81).

        The ESP32 is busy: It can only stream to one client at a time. Close any browser tabs viewing the stream before running the Python script.

        Firewall/Antivirus: Security software can block Python. Ensure it's allowed.

        Network Profile: Your computer's Wi-Fi network must be set to Private, not Public.

    How to Exit: To close the fullscreen window, you must press the 'q' key on your keyboard.
